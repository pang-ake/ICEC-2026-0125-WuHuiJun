## 4. 趋势结论

- 置信度：第 1 天 0.824 → 最近一天 0.861，变化 +0.037。呈上升趋势。
- 推理耗时：第 1 天 18.1 ms → 最近一天 39.3 ms，变化 +21.2 ms。差异来自运行环境，不是模型变化：权重自首次训练后未更新，计划任务冷启动（权重与图片首次进缓存）和机器并发负载会把单批耗时推高。
- 全期置信度区间 0.809 ～ 0.861，标准差 0.0181；单日最大波动 0.053。
- 全期推理耗时区间 17.5 ～ 40.2 ms，极差 22.7 ms。
- 累计 6 天、360 条记录，总误判 125 条（34.7%）。
