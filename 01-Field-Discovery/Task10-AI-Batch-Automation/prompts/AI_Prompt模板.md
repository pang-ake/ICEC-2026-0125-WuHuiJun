# 校园采购文本信息抽取 · AI Prompt 模板

> 用途：作为「AI 抽取脚本」的语义方案（方案 B），用于句式不规整、规则匹配失效的文本。
> 规则方案见同目录 `AI抽取脚本.py`（方案 A），两者输出字段完全一致，可互为校验。

---

## 一、系统提示（System）

```
你是公文信息抽取器。从用户提供的校园采购类文本中抽取固定字段，只输出 JSON，不输出任何解释。

输出格式（严格遵循，不要增删字段）：
{
  "date": "YYYY-MM-DD 或 null",
  "company": "单位全称 或 null",
  "amount": 整数（单位：元）或 null,
  "evidence": "原文中支撑上述字段的连续短语",
  "confidence": 0 到 1 之间的小数
}

硬性要求：
1. 只依据原文，不得推断、补全、改写单位名称。
2. 字段缺失填 null，不要用 0 或空字符串代替。
3. 「万元」必须乘以 10000 折算为元，不得保留小数单位。
4. 金额只取一个数，不要把预算、合同额、单项费用混在一起输出。
5. 无法确定时降低 confidence，并在 evidence 中给出候选原文，交由人工判断。
```

## 二、用户提示（User）

```
<text>
{粘贴单份文本全文}
</text>
```

## 三、抽取口径（必须与人工标注一致，否则一致率没有意义）

| 字段 | 口径 | 示例 |
|---|---|---|
| date | 采购 / 招标 / 实施 / 立项等**主体动作**发生的日期 | 「项目将于2024年5月18日开始配货」→ `2024-05-18` |
| company | 中标、承接、供货或赞助单位的**完整名称**，去掉引号与书名号 | 「星网锐捷网络科技有限公司」 |
| amount | 金额统一折算为**元**的整数，千分位逗号去掉 | 「12.5 万元」→ `125000` |

**已知的口径歧义（需人工确认，AI 不擅自判断）：**
- 同段出现「2024年度」与具体日期时，取具体日期；
- 赞助方 / 出资方是否算「公司名」，取决于任务定义，本批统一计入；
- 「审批日期」「立项日期」与采购实际发生日期不等同，如需区分应新增字段。

## 四、少样本示例（Few-shot）

输入：
```
关于实验室新风系统维保服务的通知
后勤保障部通知，为改善实验室空气质量，将于2024年5月20日进行新风系统维保。
本次维保服务由“绿岛环保工程有限公司”承接，维保费用共计 8,800 元。
```

输出：
```json
{
  "date": "2024-05-20",
  "company": "绿岛环保工程有限公司",
  "amount": 8800,
  "evidence": "将于2024年5月20日进行新风系统维保；由“绿岛环保工程有限公司”承接；维保费用共计 8,800 元",
  "confidence": 0.98
}
```

## 五、批处理调用方式

单份调用最稳（10 份即 10 次请求）；若要一次处理多份，用数组包裹并保持顺序：

```
请逐条抽取，输出 JSON 数组，数组长度必须等于输入条数，顺序不得调整。
[{"id": 1, "text": "..."}, {"id": 2, "text": "..."}, ...]
```

## 六、失败与降级

| 情况 | 处理 |
|---|---|
| 模型输出非 JSON | 重试 1 次，仍失败则转人工 |
| 字段为 null | 直接进入人工队列（对应校验规则 R1） |
| confidence < 0.8 | 进入人工队列（对应 R7） |
| 金额单位无法识别 | 输出 null 并在 evidence 标注原文，不猜 |

## 七、本批实测对照

| 方案 | 实现 | 10 份耗时 | 一致率 |
|---|---|---|---|
| 方案 A（规则） | `AI抽取脚本.py` | 96—206 毫秒（多次运行） | 10/10 |
| 方案 B（大模型） | 本 Prompt | 取决于模型与网络，通常 3—10 秒/份 | 用于兜底与变体文本 |

> 方案 A 用于「句式稳定 + 大批量」，方案 B 用于「句式多变 + 小批量」，两者结果不一致时以人工判定为准。
