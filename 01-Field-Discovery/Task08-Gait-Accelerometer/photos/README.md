# 采集实况截图

本目录存放课题 08 四段步态数据采集时的手机屏幕截图，均为本人在 Phyphox
「加速度（含 g）」界面下实际测量时的截屏，未经裁切、拼接或图像增强。

| 文件 | 对应状态 | 原始数据 | 截图要点 |
|---|---|---|---|
| `01-上下楼.jpg` | 上下楼 | `../raw_data/上下楼/Raw Data.csv` | x 轴 +8 m/s² 持续偏置，周期约 0.7 s 的台阶锯齿节律 |
| `02-慢走.jpg` | 平地慢走 | `../raw_data/慢走/Raw Data.csv` | x 轴摆幅 ±12，节律平缓，z 轴贴近 0 |
| `03-快走.jpg` | 平地快走 | `../raw_data/快走/Raw Data.csv` | x 轴摆幅达 ±40 m/s²，节奏 >1.6 Hz |
| `04-静止.jpg` | 静止站立 | `../raw_data/静止/Raw Data.csv` | 基线平直，仅首尾有手持抖动尖峰 |

## 为什么这几张截图能当证据

1. **界面唯一性**：截图来自 Phyphox 的实时测量界面，横轴是秒、纵轴是 m/s²，
   曲线带毛刺与漂移，是传感器真实采样而非函数画图。
2. **与 CSV 可对照**：截图上的幅度、时长、偏置方向与对应 CSV 的统计量一致
   （例如快走 x 轴 ±40 对应 `analysis/特征统计表.csv` 中该段 σ 值）。
3. **四段互补**：四种状态的曲线形态肉眼即可区分，正是本项目"阈值规则"的直观依据。
